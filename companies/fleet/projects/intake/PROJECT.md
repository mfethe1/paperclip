---
name: Intake
slug: intake
description: Landing zone for new requests from any channel. The Chief of Staff triages everything here into a real project within a day.
owner: chief-of-staff
---

Anything that doesn't obviously belong to an existing project starts here: requests
from Telegram/Discord/Buzz, ideas, and bugs noticed in passing. An issue should not
stay in Intake longer than one triage pass. It moves to a project with acceptance
criteria, or it is closed with a reason.
